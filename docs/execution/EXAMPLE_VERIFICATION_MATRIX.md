# Example verification matrix

This inventory is enforced by `cargo xtask examples-verify`. The default command is credential-free: it discovers every YAML file under `examples/` and `fixtures/compat/`, requires one row per file, runs `check` and `plan` with the documented exit codes, and then runs the repository's canonical deterministic and mock journeys. `cargo xtask examples-verify-live-openai` is the explicit bounded live gate for the original maintained OpenAI inventory. Independently cataloged example 21 uses its own leased `preflight` and `remediate` operations in the standalone demo; it does not silently join the older paid suite.

`N/A` means the check does not apply to that example. `Canonical` means the behavior is exercised by the existing deterministic example or acceptance runner. `Opt-in` means credentials or an external service are required and the default gate does not claim execution.
