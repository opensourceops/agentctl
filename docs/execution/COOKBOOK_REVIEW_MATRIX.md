# Cookbook review matrix

This matrix describes the maintained public workflows after the September 2026 review. Each direct path begins with the complete package and published `setup.py`, then `agentctl check local.workflow.yaml`, `plan`, `run --workspace . --db state.db`, and `inspect RUN_ID --db state.db`. These are ordinary CLI invocations; `run.py` is optional acceptance instrumentation. The tutorials include full commands, prerequisites, cleanup and recovery details. Python means the pinned virtual environment in `examples/devops/requirements.txt`; host helpers are trusted processes, not a separate OS sandbox.

Every primary direct journey passed again using the installed clean `4a22f7f733c5c722263b956b59f36107ec398fc7` candidate and complete packages. The final Linux/macOS/Windows runner, release and paired-site gates passed separately. The scenario variants below retain their development-source evidence; they are not relabeled as new final-source executions.
